# HƯỚNG DẪN LƯU TRỮ HÌNH ẢNH HÀNG HÓA

Thư mục này dùng để chứa toàn bộ hình ảnh minh họa cho các mặt hàng trong hệ thống kho:
`E:\gemini\hệ thống quản lý kho\backend\static\products\`

---

## 1. Cách 1: Tải trực tiếp trên giao diện Web (Khuyên dùng — Tiện nhất)

1. Đăng nhập với quyền **Thủ kho** (`thukho` / `thukho123`) hoặc **Admin** (`admin` / `admin123`).
2. Vào trang **Hàng hóa**.
3. Bấm biểu tượng **Sửa** (cây bút) bên cạnh mặt hàng muốn đổi ảnh (hoặc tạo mặt hàng mới).
4. Bấm nút **"Tải ảnh từ máy..."**, chọn file ảnh bất kỳ từ máy tính của bạn (hỗ trợ JPG, PNG, WEBP, GIF).
5. Bấm **Cập nhật** $\rightarrow$ Hệ thống tự động lưu vào thư mục này với tên file tương ứng mã SKU.

---

## 2. Cách 2: Chuẩn bị ảnh thủ công và chép vào thư mục này

Bạn có thể chuẩn bị sẵn các file ảnh và đặt tên theo **Mã SKU** tương ứng (`.jpg` hoặc `.png`), sau đó copy thẳng vào thư mục:
`E:\gemini\hệ thống quản lý kho\backend\static\products\`
