3. SO SÁNH TRƯỚC / SAU CẠNH NHAU (VISUAL CODE DIFF)

3.1 Sửa hàm tính Tồn đầu kỳ & Phân tách Nghiệp vụ (inventory_service.py)

Chuyển từ đọc balance_after của 1 dòng sang tính tổng đại số SUM(quantity_change); phân tách giao dịch Hủy phiếu & Kiểm kê khỏi Nhập/Xuất thương mại.

❌ TRƯỚC: Code hiện tại (Bị sai số liệu & sai nghiệp vụ)
# 1. Tồn đầu kỳ: Lấy balance_after của dòng gần nhất last_entry_before = ( db.query(StockLedger) .filter( StockLedger.product_id == product.id, StockLedger.transaction_date < from_date, ) .order_by(StockLedger.transaction_date.desc(), StockLedger.id.desc()) .first() ) opening_stock = last_entry_before.balance_after if last_entry_before else 0 # 2. Gom nhóm trong kỳ: Gom thuần túy theo dấu âm dương period_import = sum(e.quantity_change for e in period_entries if e.quantity_change > 0) period_export = sum(abs(e.quantity_change) for e in period_entries if e.quantity_change < 0) closing_stock = opening_stock + period_import - period_export
✅ SAU: Đề xuất khắc phục (Toán học bất biến & Chuẩn kế toán kho)
# 1. Tồn đầu kỳ: Tính tổng đại số lũy kế trước kỳ bằng SQL aggregation opening_stock = ( db.query(func.coalesce(func.sum(StockLedger.quantity_change), 0)) .filter( StockLedger.product_id == product.id, StockLedger.transaction_date < from_date, ) .scalar() ) # 2. Gom nhóm trong kỳ: Bóc tách đúng bản chất giao dịch kho comm_import = sum(e.quantity_change for e in period_entries if e.transaction_type == 'IMPORT') comm_export = sum(abs(e.quantity_change) for e in period_entries if e.transaction_type == 'EXPORT') adjustments = sum(e.quantity_change for e in period_entries if e.transaction_type == 'ADJUSTMENT') # Hoàn trả phiếu hủy không làm thổi phồng nhập mua/xuất bán closing_stock = opening_stock + comm_import - comm_export + adjustments

3.2 Sửa thứ tự nạp giao dịch trong seed_data.py

Chuyển từ việc nạp từng nhóm nhập/xuất rời rạc sang hàng đợi sự kiện (Event Queue) sắp xếp tuần tự theo trục thời gian.

❌ TRƯỚC: Nạp nhập trước, nạp xuất sau lệch ngày
# Nạp các phiếu nhập trước (ngày 5, 14, 22) record_import("PN-202606-001", ..., datetime(2026, 6, 5)) record_import("PN-202606-002", ..., datetime(2026, 6, 14)) record_import("PN-202606-003", ..., datetime(2026, 6, 22)) # Sau đó mới chạy vòng lặp xuất từ ngày mùng 2! for day in [2, 5, 7, 10, ...]: record_export(f"PX-202606-{day:02d}", ..., datetime(2026, 6, day))
✅ SAU: Gom tất cả vào Event Queue & Sắp xếp theo ngày
# Đưa tất cả sự kiện nhập/xuất vào 1 danh sách events = [] events.extend(generate_all_import_events()) events.extend(generate_all_export_events()) # Sắp xếp tuần tự nghiêm ngặt theo thời gian tăng dần events.sort(key=lambda x: x["note_date"]) # Thực thi tuần tự: ID và timestamp luôn tăng dần đơn điệu for ev in events: execute_event(ev)
